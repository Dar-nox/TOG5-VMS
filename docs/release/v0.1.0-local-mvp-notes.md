# TOG 5 VMS v0.1.0 Local MVP Notes

TOG 5 VMS v0.1.0 is a local-first Windows desktop MVP for vehicle maintenance records.

## Included

- Local vehicle records with stored vehicle photos.
- Maintenance templates, applicability preview, schedule sync, due status, and in-app alerts.
- Maintenance completion and service history with local receipt/photo references.
- Fuel logs with local receipts and official full-tank fuel efficiency calculations.
- Manual expenses and local cost reports.
- Local backup and restore with manifest/checksum validation.
- Settings for local profile, display preferences, alert preferences, backup reminders, and data safety visibility.
- Real dashboard overview powered by local data.

## Local Data

The app stores its SQLite database and managed files in the local app-data folder. It does not upload user data or use cloud sync.

## Known Limitations

- The installer is unsigned and may show Windows SmartScreen warnings.
- Database encryption is not enabled.
- Startup-on-boot is a saved preference only and is not registered with Windows yet.
- Backup packages use a local folder-style `.tog5backup` format.
- There is no auto-updater, OCR, report export, online account, or native OS notification system yet.
